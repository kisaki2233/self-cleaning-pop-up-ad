

## 6. 运行时验证状态

当前构建环境没有连接 Android 真机，也没有可用的系统镜像，因此**未完成真机/模拟器上的点击验证**。已完成的验证是：

- 编译通过；
- 资源链接通过；
- Lint 通过（0 error，65 warnings）；
- APK 签名校验通过（v2，证书与 v1.0.0 相同，可覆盖升级）；
- Manifest/权限/组件检查通过；
- `aapt dump badging` 确认 versionCode 4 / versionName 1.1.0。

v1.1.0 新增应用白名单/黑名单，并复用 `AppPickerActivity`：

- 白名单为空 = 全部 App；非空 = 只处理白名单。
- 黑名单优先；白名单/黑名单保存在 SharedPreferences 且互斥。
- 两份名单同时控制开屏跳过和以该 App 为来源的误触返回；跳转拦截名单仍只控制落地目标。

v1.0.2 根据两段录屏修正了三处逻辑：

1. 百度网盘同时被勾选在跳转名单中时，过去会被 `scheduleScan` 排除，导致它自己的「跳过」永远不点。现在名单只影响返回判定，不再影响开屏扫描。
2. 桌面、最近任务、系统 UI 会清空来源 App，因此从桌面/最近任务正常打开目标 App 不会被返回。
3. 返回判定优先使用“来源页识别到明确跳过按钮”的广告证据；没有证据时收紧为 5 秒内且最近有点击，避免目标 App 之间的正常跳转被误拦。

录屏只能证明界面现象，无法替代真机点击验证。建议重点验收下面的第 11–15 项，并用 `adb logcat -s QingPing` 查看 `ad phase`、`jump?`、`block jump` 日志。

## 7. 已知构建注意事项

1. **debug 签名**：仅适合个人侧载。正式分发请生成自己的 release keystore，并修改 `app/build.gradle` 的 `signingConfigs`。
2. **首次构建需要网络**：Gradle 需要下载 AGP 和 Android 依赖；之后可离线构建。
3. **SDK 34**：如果本机只有更高版本 SDK，可安装 Platform 34，或把 `compileSdk`/`targetSdk` 改为本机已安装版本（建议至少 34）。
4. **Windows 路径**：项目路径包含中文通常可以构建；如果遇到 AAPT/Gradle 路径问题，可放到纯英文路径下。
