
```properties
sdk.dir=C:/Users/your-name/AppData/Local/Android/Sdk
```

Android Studio 打开项目时会自动生成该文件。

## 7. 已知构建注意事项

1. **debug 签名**：仅适合个人侧载。正式分发请生成自己的 release keystore，并修改 `app/build.gradle` 的 `signingConfigs`。
2. **首次构建需要网络**：Gradle 需要下载 AGP 和 Android 依赖；之后可离线构建。
3. **SDK 34**：如果本机只有更高版本 SDK，可安装 Platform 34，或把 `compileSdk`/`targetSdk` 改为本机已安装版本（建议至少 34）。
4. **Windows 路径**：项目路径包含中文通常可以构建；如果遇到 AAPT/Gradle 路径问题，可放到纯英文路径下。
